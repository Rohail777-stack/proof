# Contributing to Proof

Proof is an early open-source experiment, and contributions are welcome.

You can contribute by:

- Improving the product
- Building integrations
- Improving the verification flow
- Improving accessibility
- Fixing bugs
- Improving documentation
- Challenging or extending the concept

## Getting started

1. Fork the repository
2. Create a branch
3. Make your changes
4. Open a pull request

For larger changes, please open an issue first so the idea can be discussed.

## Product principles

Proof is built around a simple principle:

> Preserve what people already said. Don't manufacture it.

Contributions should respect:

- Author consent
- Privacy
- Verification
- Original context
- Transparency

## Questions and ideas

If you're unsure whether an idea fits the project, open an issue and start a discussion.
